# Network Risk Assessment and Infrastructure Upgrade

## Project Overview

This project evaluates the network infrastructure of a simulated organization, International Plastics Inc., to identify security, availability, and operational risks within the existing environment.

The assessment examines the organization's current network architecture and recommends infrastructure improvements designed to strengthen security, improve reliability, and support business operations.

## Business Scenario

International Plastics Inc. required an evaluation of its existing network environment to identify vulnerabilities, infrastructure limitations, and opportunities for modernization.

The project combines risk assessment with network design recommendations to demonstrate how technology improvements can reduce organizational risk while improving network performance and resilience.

# Network Risk Assessment and Upgrade

## Overview
This project documents a network risk assessment and subsequent upgrade
focused on reducing security, availability, and operational risk.

## Objectives
- Identify risks associated with legacy network infrastructure
- Evaluate gaps in security and availability controls
- Recommend and document network upgrades to reduce risk

## Scope
Assessment of the current network state, risk identification, and design of
network improvements aligned with security and governance best practices.

## Notes
Originally completed as an academic project and adapted for portfolio use.
All details are generalized and anonymized.
